使用笔记

Markdown 使用笔记

创建时间：2026-02-28 更新时间：2026-02-28

基础文本格式化

  • 标题（1-6级）：# 加空格，#数量对应级别，最多6级

# 一级标题

## 二级标题

### 三级标题

#### 四级标题

##### 五级标题

###### 六级标题
  • 加粗：包裹文本

**加粗文本**
  • 斜体：*包裹文本

*斜体文本*
  • 删除线：~~包裹文本

~~删除线文本~~
  • 引用：> 加空格

> 引用内容

列表排版

  • 无序列表：- 加空格，支持嵌套

- 列表项1

  - 嵌套项
  • 有序列表：数字+. 加空格

1. 列表项1

2. 列表项2

链接与图片

  • 链接：\显示文本\

[百度](https://www.baidu.com)
  • 图片：!\[\]包裹alt文本，加链接

![风景图](https://example.com/fengjing.jpg)

代码块与行内代码

  • 行内代码：\\包裹代码片段

这里有`print("Hello")`行内代码
  • 代码块：\\\`包裹，可加语言

console.log("Hello Markdown")

表格

  • 表格：|分隔列，-分隔表头，:控制对齐

| 表头1 | 表头2 |

| :--- | :---: |

| 内容1 | 内容2 |

其他基础语法

  • 分割线：三个减号/星号/下划线

---
  • 转义字符：\加语法符号

\# 这不是标题
  • 脚注：文本[^标识]，文末添加脚注

文本[^1]

[^1]: 脚注内容

进阶语法

  • 表格合并：rowspan/colspan属性

| rowspan="2" | 单元格1 |

|  | 单元格2 |
  • 目录生成：\[TOC\]自动生成

[TOC]
  • 文本高亮：==包裹文本

==高亮文本==
  • 任务列表：- [ ] 待办，- [x] 已办

- [ ] 待办事项

- [x] 已办事项
  • 数学公式：$行内公式，$$公式块

$a^2 + b^2 = c^2$

$$f(x) = x^2$$
  • 图片调整：调整大小+居中

![风景图](https://example.com/fengjing.jpg =300x200)

<center>![风景图](https://example.com/fengjing.jpg)</center>
