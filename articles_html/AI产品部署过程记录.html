前置环境

  1. win11虚拟机
  2. GIT 和 Node

基础部署

进入官网：openclaw官网

1、执行npm安装命令


# Install OpenClaw（安装openclaw）

$npm i -g openclaw

2. 执行初始化openclaw命令


# Meet your lobster（开始使用）

$openclaw onboard

3. 产品的介绍和风险说明

4. 部署模式选择快速


 Onboarding mode



│  QuickStart

5. 选择大模型平台，并配置ApiKey

5. 选择消息机器人，并配置AppId和AppSecret

6. 选择是否现在配置 skills 和 hooks

skills选择no，后续按需配置。
hooks默认全选

7. 选择使用时的界面类型

8. 完成

9. 相关命令


#停止服务

openclaw gateway stop



#启动服务

openclaw gateway start



#重启服务

openclaw gateway restart



#查看服务状态

openclaw gateway status



#重新运行配置

openclaw configure
