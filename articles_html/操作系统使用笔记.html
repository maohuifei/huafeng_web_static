MacOS

取消系统更新通知

核心屏蔽法：修改 Hosts 文件 (阻止连接更新服务器)

此方法直接阻止 Mac 访问苹果的更新服务器。

  1. 打开 Hosts 文件：
  • 打开 终端。
  • 输入 sudo nano /etc/hosts 并按回车。
  • 输入管理员密码。
  1. 添加屏蔽规则：
  • 在文件末尾添加以下行：

        127.0.0.1 swscan.apple.com

        127.0.0.1 swdist.apple.com

        127.0.0.1 swcdn.apple.com

        127.0.0.1 gdmf.apple.com

        127.0.0.1 mesu.apple.com

        127.0.0.1 xp.apple.com
  • (注意：去掉行首的 http://，仅保留域名)
  1. 保存并生效：
  • 按 Control + O 保存，按 Control + X 退出 nano 编辑器。
  • 执行以下命令刷新 DNS 缓存：

        sudo dscacheutil -flushcache

        sudo killall -HUP mDNSResponder
  1. 效果： Mac 将无法连接苹果更新服务器，从根本上阻止检测到新更新，小红点通常会随之消失。
  2. 关键词： 修改Hosts屏蔽更新, 阻止Mac连接更新服务器, 屏蔽更新域名列表

消除小红点：终端命令 (快速清除标记)

如果小红点依然存在（通常是之前检测到的更新标记），可用命令清除：

  1. 清除现有小红点：

    defaults write com.apple.systempreferences AttentionPrefBundleIDs 0

    killall Dock
  • 此命令重置通知标记并重启 Dock 进程，立即消除系统偏好设置图标上的小红点。

安装(镜像、国内第三方脚本)


/bin/zsh -c "$(curl -fsSL <https://gitee.com/cunkai/HomebrewCN/raw/master/Homebrew.sh>)"

/bin/zsh -c "$(curl -fsSL <https://gitee.com/cunkai/HomebrewCN/raw/master/HomebrewUninstall.sh>)"

默认命令行安装的软件包路径：usr/local Homebrew安装的路径：opt/homebrew

查看端口被哪个程序占用

sudo lsof -i tcp:port

示例：

sudo lsof -i tcp:8080 查看8080端口是否被占用

  1. 看到进程的PID，可以将进程杀死。
