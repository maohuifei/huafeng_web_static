接口设计

1.URI 设计

  • 名词复数：/users, /orders
  • 关联嵌套：/users/{uid}/orders/{oid}
  • 版本控制：/api/v1/users 或请求头 Accept: application/vnd.api.v1+json
  • 过滤参数：GET /users?role=admin&page=1&size=20&sort=-createdAt

2.HTTP 方法

表格

方法 幂等 用途 示例
--- --- --- ---
GET ✔️ 查询 / 列表 GET /users

PUT ✔️ 全量更新 PUT /users/{id}
PATCH ❌ 部分更新 PATCH /users/{id}
DELETE ✔️ 删除 DELETE /users/{id}

安全规范

1. 传输安全

  • 强制 HTTPS，HTTP 301 重定向
  • 禁用 TLS 1.0/1.1，使用 TLS 1.2+

2. 鉴权

  • 鉴权：JWT/OAuth2.0，Authorization: Bearer {token}

3. 接口防护

  • 限流：X-RateLimit-Limit: 100，X-RateLimit-Remaining: 90
  • 防重放：请求头带 nonce/timestamp
  • SQL 注入：使用预编译语句 / ORM，禁止字符串拼接 SQL
  • XSS：输入转义，输出编码，使用 CSP
  • CSRF：验证 Referer，使用 CSRF Token

4. 数据安全

  • 敏感数据加密存储（密码 bcrypt，手机号 / 身份证 AES）
  • 日志脱敏：屏蔽手机号、身份证、密码等
  • 接口返回：不泄露敏感字段（如密码、token）
