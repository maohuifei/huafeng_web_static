## 命名规范

| 类型      | 规范                      | 示例                                 |
| ------- | ----------------------- | ---------------------------------- |
| 目录      | 全小写 + 短横线 `-`           | `user-center`, `order-detail`      |
| 变量      | 小驼峰 `camelCase`         | `userName`, `orderList`            |
| 常量      | 置作用域顶，全大写 + 下划线 `_`     | `MAX_RETRY`, `BASE_API_URL`        |
| 方法 / 函数 | 小驼峰 + 动词前缀              | `getUserInfo`, `updateOrderStatus` |
| 类 / 接口  | 大驼峰 `PascalCase`        | `UserService`, `OrderController`   |
| 文件      | 组件 / 类：大驼峰；其他：小驼峰 / 短横线 | `UserForm.vue`, `date-utils.js`    |

## JavaScript 

### 1. 核心语法

- 优先使用 `const`/`let`，
- 箭头函数用于匿名回调：`const handleClick = () => {}`
- 模块导入导出：
```js
// 导出
export const getUser = () => {}
export default UserService
// 导入
import UserService, { getUser } from './user-service'
```

### 2. 代码风格
- 异步优先 `async/await`，顶层 `.then`
- 类型校验：使用 TypeScript 或 JSDoc 标注类型

# 接口设计

## 1.URI 设计

- 名词复数：`/users`, `/orders`
- 关联嵌套：`/users/{uid}/orders/{oid}`
- 版本控制：`/api/v1/users` 或请求头 `Accept: application/vnd.api.v1+json`
- 过滤参数：`GET /users?role=admin&page=1&size=20&sort=-createdAt`

## 2.HTTP 方法

表格

|方法|幂等|用途|示例|
|---|---|---|---|
|GET|✔️|查询 / 列表|`GET /users`|
|POST|❌|创建|`POST /users`|
|PUT|✔️|全量更新|`PUT /users/{id}`|
|PATCH|❌|部分更新|`PATCH /users/{id}`|
|DELETE|✔️|删除|`DELETE /users/{id}`|

## 3.响应格式

- 成功响应：
 ```json
   {
   "code": 200,
   "data": {},
  "pagination": { "total": 100, "current": 1, "size": 20, "pages": 5 },
  "message": "success"
   }
   ```
- 错误响应：
 ```json
  {
  "code": 40001,
  "message": "参数错误",
   "details": "email 格式无效"
 }
 ```

# 安全规范

## 1. 传输安全

- 强制 HTTPS，HTTP 301 重定向
- 禁用 TLS 1.0/1.1，使用 TLS 1.2+

## 2. 鉴权

- 鉴权：JWT/OAuth2.0，`Authorization: Bearer {token}`

## 3. 接口防护

- 限流：`X-RateLimit-Limit: 100`，`X-RateLimit-Remaining: 90`
- 防重放：请求头带 `nonce`/`timestamp`
- SQL 注入：使用预编译语句 / ORM，禁止字符串拼接 SQL
- XSS：输入转义，输出编码，使用 CSP
- CSRF：验证 Referer，使用 CSRF Token

## 4. 数据安全

- 敏感数据加密存储（密码 bcrypt，手机号 / 身份证 AES）
- 日志脱敏：屏蔽手机号、身份证、密码等
- 接口返回：不泄露敏感字段（如密码、token）
