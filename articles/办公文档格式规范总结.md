# 思源字体商用说明

- 协议：SIL OFL 1.1 开源协议，个人/企业免费商用，无授权风险

# 页面基础设置（A4）

- 页边距：上3.7cm、下3.5cm、左2.8cm、右2.6cm

- 版心：156mm×225mm，每页22行、每行28字

- 页码：宋体四号，格式「-1-」，奇数页居右、偶数页居左

# 字体字号规范

|文档层级|思源字体|字号|格式要求|行距|
|---|---|---|---|---|
|主标题（文档大标题）|思源宋体 Bold（粗体）|二号（22pt）|居中（字体粗体自带醒目效果）|固定值36磅|
|一级标题（章节标题）|思源黑体 Bold（粗体）|三号（16pt）|左空2字|固定值28磅|
|二级标题（小节标题）|思源宋体 Regular（常规）|三号（16pt）|左空2字|固定值25磅|
|三级标题（子项标题）|思源宋体 Regular（常规）|三号（16pt）|左空2字，可加粗|固定值28磅|
|四级标题|思源宋体 Regular（常规）|三号（16pt）|左空2字|固定值28磅|
|正文|思源宋体 Regular（常规）|三号（16pt）|首行缩进2字符、两端对齐|固定值28磅|
|英文/数字|思源宋体/黑体 配套西文|同对应层级字号|与中文统一排版|同对应层级行距|
# 标题编号与段落间距规范

## 标题编号

- 一级标题：一、二、三、……（中文顿号，左空2字）

- 二级标题：(一)(二)(三)……（无顿号，左空2字）

- 三级标题：1. 2. 3. ……（英文句号，左空2字）

- 四级标题：(1)(2)(3)……（无句号，左空2字）

## 段落间距

- 主标题/一级标题：段前12磅、段后12磅

- 二级标题：段前6磅、段后6磅

- 三级/四级标题：段前3磅、段后3磅

- 正文：段前/段后0磅，首行缩进2字符（禁止空格缩进）
